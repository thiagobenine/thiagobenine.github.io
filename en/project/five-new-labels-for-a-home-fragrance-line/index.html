The request

The same home fragrance brand came back with 5 new labels for the printer.

What I did

I made the three labels for a new fragrance (bottle, reed diffuser and room spray), the label for a 400 ml bottle, and redrew as vector a small 5 x 5 cm label that only existed as an image.

I followed the style approved in the first project and delivered print-ready files.
