WordPress plugin that publishes news stories to Instagram and Facebook

A custom plugin that takes every story from a news portal to Instagram and the Facebook Page, with an automatic graphic.

The request

A news portal published on WordPress and then repeated everything by hand on Instagram and Facebook.

What I did

I built a custom plugin connected to Meta's official API that publishes by category, with caption and hashtag templates, automatic or manual mode, schedules, a history with errors and retries, and a lock against duplicate posts. In the final version, the plugin creates the Instagram graphic on its own with a headline band and logo, with separate text for each network and an SEO-minded summary.

The result

The code was handed over open and commented, with 180 automated tests and zero failures, a second test installation, and installation and replication manuals.
