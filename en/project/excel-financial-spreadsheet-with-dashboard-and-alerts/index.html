The request

A store owner didn't want a system, just a spreadsheet where he could enter data and see charts and alerts.

What I did

I built the spreadsheet using only formulas compatible with his Excel version, with no macros. It has highlighted, protected input fields, upcoming bills to pay and a visual diagnostic dashboard.

The result

I only delivered it once the dashboard numbers matched his.
