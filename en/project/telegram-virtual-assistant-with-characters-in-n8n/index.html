Conversation on Telegram: the menu with the four profiles, a character replying, memory that is only cleared after confirmation and the English teacher correcting a sentence in Portuguese.

The request

The client wanted a chatbot with fictional characters, each with its own way of talking, one of them an English teacher.

What I did

I built the virtual assistant in n8n, connected it to Telegram and packaged it in Docker.

The result

An illustrated guide shows how to install it and adjust the characters.
