The request

A platform that connects restaurants with affiliates had bugs in the menu, dashboards and signup.

What I did

I fixed the 5 reported bugs and the broken affiliate links, and closed holes such as affiliates being able to change their own balance and the order total being calculated in the browser. I created new rules for payouts on fixed dates, automatic cancellation of orders stuck for 24 hours and counting a sale only after the order is completed.

The result

That came to about 25 code deliveries and 23 database changes, all live before the project was signed off.
