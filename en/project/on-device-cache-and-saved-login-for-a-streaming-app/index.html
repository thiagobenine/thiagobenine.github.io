On-device cache and saved login for a streaming app

The live streaming app now opens instantly with the latest content, works offline and keeps users logged in.

Home, profile and ranking opened with the phone in airplane mode, using content stored on the device. Labels translated for this English version; the original is in Portuguese.

The request

The app for a gaming live streaming platform fetched everything from the server on every launch and sometimes asked users to log in again.

What I did

I stored the feed, clips, games, profile, live streams, rankings and skins on the phone, along with photos and thumbnails, so screens open instantly with the latest content and refresh in the background. The login now survives closing and updating the app, all account data is cleared on logout, and stored data has a size limit, with the oldest items removed first.

The result

In tests on the Android emulator and the iPhone simulator, the app reopened with content in under a second and worked offline with no broken images.
