The second hotel's Tag Manager, with 19 GA4, Google Ads and Pixel tags and a trigger for each click.

The request

Two hotel websites were about to start advertising without measuring bookings or inquiries.

What I did

I built the Tag Manager setup for both sites from scratch, with 14 and 19 tags, set up GA4 to track booking and WhatsApp clicks and form submissions, with 3 events marked as key events, and installed the Meta Pixel with view, contact and lead events. I removed 2 old containers after backing them up, linked the new Google Ads account to GA4 with 3 imported conversions and checked everything in real time.

The result

The code for the second site was handed off ready for the developer to install.
