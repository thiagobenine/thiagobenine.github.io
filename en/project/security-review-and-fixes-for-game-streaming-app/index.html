The request

The same game streaming platform came back for a security review with fixes.

What I did

I closed holes in file uploads, access code limits, stream start and end notifications and error messages, and fixed signup and the profile menu. The Live tab dropped from 6 to 10 queries per change to 1 to 3, and the messaging bot stopped querying the database for regular accounts.

The result

I also built an option to delete a chat just for yourself, which passed 21 of 21 database tests, and everything shipped in public version 1.2 of the app.
