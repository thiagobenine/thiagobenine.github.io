Official WhatsApp API in a clinic's CRM, with an automated campaign

A number connected to the CRM through the official API while keeping the phone app, with approved templates and a campaign bot.

The request

An aesthetics clinic wanted to use the official WhatsApp API on a second number without giving up answering in the phone app.

What I did

I connected the number to the CRM through the official API in coexistence mode, and the conversations started flowing into the sales pipeline. I created marketing message templates, approved by Meta, that greet the contact by name when there is one, and a campaign bot in a new 6-stage pipeline that only fires when the lead is moved to the send stage.

The result

Anyone who doesn't reply within 24 hours goes to a dedicated column, and the team got a step-by-step guide to moving leads and adding the payment method in Meta.
