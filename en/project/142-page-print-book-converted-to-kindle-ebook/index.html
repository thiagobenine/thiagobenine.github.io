The clickable table of contents on an e-reader screen, linked to the first screen of each chapter, and the opening, quote, text and closing sequence repeated across all nine chapters (the book's titles and text are left out). Labels translated for this English version; the original is in Portuguese.

The request

An author had a 142-page A5 book and wanted to publish the Kindle version.

What I did

I converted it to EPUB 3 with each chapter, each quote and the About the Author page starting on its own screen, plus a clickable table of contents.

The result

The file passed the format's official validation without a single error, and I checked 112 screens in the reader before delivery.
