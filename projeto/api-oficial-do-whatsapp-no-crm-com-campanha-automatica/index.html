API oficial do WhatsApp no CRM de uma clínica, com campanha automática

Número ligado ao CRM pela API oficial sem perder o app no celular, com modelos aprovados e robô de campanha.

O pedido

Uma clínica de estética queria usar a API oficial do WhatsApp num segundo número sem deixar de atender pelo app do celular.

O que eu fiz

Liguei o número ao CRM pela API oficial com coexistência, e as conversas passaram a entrar no funil de vendas. Criei os modelos de mensagem de marketing, aprovados pela Meta, com saudação pelo nome do contato quando há nome, e um robô de campanha num funil novo de 6 etapas, que só dispara quando o lead é movido para a etapa de envio.

O resultado

Quem não responde em 24 horas vai para uma coluna própria, e a equipe recebeu o passo a passo para mover os leads e cadastrar a forma de pagamento na Meta.

O que eu entreguei

  • 03Modelos de marketing aprovados pela Meta
  • 04Robô de campanha num funil de 6 etapas
  • 05Coluna para quem não respondeu em 24 horas
  • 06Passo a passo para a equipe
