Sobre o projeto

O cliente precisava com urgência de uma landing page elegante e legível em vários idiomas. A página foi feita em WordPress com Elementor, em modo escuro com detalhes prateados, tradução pelo GTranslate com troca automática pelo idioma do navegador, domínio apontado e SSL. Ficou leve e bem resolvida no celular.

O que foi entregue

  • Landing page em WordPress e Elementor
  • Seletor de idiomas com tradução automática
  • Domínio e SSL configurados
  • Versão para celular
