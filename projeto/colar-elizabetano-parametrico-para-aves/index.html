Sobre o projeto

Para proteger aves de portes diferentes, era preciso um colar elizabetano com medidas fáceis de ajustar. O colar foi modelado de forma paramétrica no FreeCAD e gerou 19 modelos prontos para impressão 3D, com gravação de tamanho em cada peça. O projeto saiu melhor do que o pedido, com as características técnicas que o uso exigia.

O que foi entregue

  • Modelo paramétrico no FreeCAD
  • 19 tamanhos prontos para imprimir
  • Pranchas com tamanhos e gravações
