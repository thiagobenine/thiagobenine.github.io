Colar elizabetano para aves modelado por parâmetros: um desenho só gera os 19 tamanhos, do menor ao maior.

O pedido

Para proteger aves de portes diferentes, era preciso um colar elizabetano com medidas fáceis de ajustar.

O que eu fiz

Modelei o colar de forma paramétrica no FreeCAD e gerei 19 modelos prontos para impressão 3D. Cada peça leva o tamanho gravado.

O resultado

O trabalho saiu melhor do que o pedido, com as características técnicas que o uso exigia.
